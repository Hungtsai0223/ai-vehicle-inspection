# Hackathon Demo Script · 2–3 minutes

開始前：開 `/demo`，選 Mock 展示環境、確認瀏覽器可操作。手機使用 HTTPS；沒有可用相機就明確選 Demo 模式。所有結果、影像、KPI 與表格數字都是展示資料，真正 AI 待隊友串接。

| --------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 0:00–0:20 | 說明現況                                 | 共享汽車還車需要逐張拍照，營運人員再人工審閱大量影像，容易有模糊與漏拍。                                |
| 0:20–0:40 | /demo → 完整使用者流程 → 開始車況掃描    | 我們把操作改成沿車走一圈，由介面引導距離、方向與拍攝品質。                                              |

## Rehearsal shortcuts and recovery

- 時間不足：/demo → 多處車損 → 查看完整檢測結果 → Dashboard。
- 相機無法啟用：按「改用 Demo 模式」，明確說明使用展示掃描。
- 後端失敗：錯誤保留，按「使用 Demo 結果繼續」才進入模擬結果；不得稱已分析本次照片。
- 展示結束：按「重新開始 Demo」，回到 /return，避免下一輪沿用上一輪結果。
- production 的 Integration Debug 不可使用；評審不需查看 raw JSON 或環境設定。
